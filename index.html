How the frame gets here

01

Decode

The source video is read frame by frame on the server, the same job any UVC-class webcam driver does before handing frames to an application.

02

Detect

Each frame runs through a YOLO model, which returns bounding boxes and confidence scores for whatever it recognizes.

03

Annotate

Boxes and labels are drawn directly onto the frame before it leaves the server — what you see is exactly what the model saw.

04

Stream

The annotated frame is pushed to this page over WebRTC, the same peer-to-peer protocol behind most modern video calling.

On resolution: consumer webcams climbed from 320×240 in the mid-1990s to 720p and 1080p as USB and broadband speeds caught up, with 4K now common at the high end. This pipeline is built to scale the same way — it runs today's detection loop on modest hardware, with a documented path to swap in GPU-accelerated decoding and inference without changing the surrounding architecture.
